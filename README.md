# Business Intelligence – Power BI

## Présentation

Projet réalisé dans le cadre d'une expérience professionnelle chez ASTEO, filiale du groupe SUEZ.

L'objectif était de développer et améliorer des outils de reporting et de suivi de la performance opérationnelle.

## Travaux

- Développement de tableaux de bord Power BI
- Création et optimisation de mesures DAX
- Utilisation de Power Query
- Exploitation de données provenant de plusieurs sources
- Suivi de 133 indicateurs de performance
- Analyse de KPI
- Optimisation du reporting
- Contribution au remplacement d'un outil existant par Power BI

## Technologies

- Power BI
- DAX
- Power Query
- SQL
- PostgreSQL
- Excel

## Confidentialité

Les données, requêtes métier et tableaux de bord professionnels originaux ne sont pas publiés.

Ce dépôt présente uniquement la démarche technique et des exemples génériques partageables.
